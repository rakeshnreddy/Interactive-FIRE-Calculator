## Changed behavior

- **Wide Option A Split Financial Workbench & single-border input controls (`R1`, `src/workspace.css`, `src/studios.css`, `DESIGN.md`):**
  - Scoped `@layer workspace` input border styling in `src/workspace.css` from descendant `.field input` to direct-child `.field > input` so inputs nested inside `.calculator-input-control` no longer inherit a second box-in-a-box inner border across all 75 shared studio calculators and dedicated planners (`innerInputBorders: 0`).
  - Expanded `.workspace:has(.calculator-detail)` to `min(1320px, calc(100% - clamp(1.25rem, 3.2vw, 2.75rem)))`, compacted `.calculator-detail > .calculator-library-heading` into a 2-column header with right-aligned `.calculator-toolkit-backlink` on `>= 721px`, and set `.calculator-detail-grid` to `minmax(440px, 500px) minmax(0, 1fr)` on `>= 1041px` (gracefully stacking `1fr` on `<= 1040px`).
  - Aligned left (`Inputs / Run the estimate`) and right (`Result / Primary metric`) panel headings onto the same horizontal baseline, quieted `.estimate-customization` into a single-row bottom-ruled jump bar, aligned `.calculator-input-grid` with `align-items: start`, tightened `.calculator-input-control` to `36px`, and compacted `.calculator-options-shell`, `.calculator-result-action`, and `.calculator-scenario-panel` so primary inputs and `View result` sit well above the `900px` desktop fold (`viewResultBottom: 567–774px`).
- **Above-the-fold Result Ledger, smart 6-column metrics & clean Studio Visual (`R2`, `src/CalculatorLibrary.tsx`, `src/studios.css`, `src/styles.css`):**
  - Moved `<CalculatorStudioVisual>` directly beneath `.calculator-result-metrics` and reconciliation strips and ahead of `<CalculatorScopeNotice>` and `<VariantChips>` so the visual chart is immediately visible on desktop without scrolling (`visualTop: 468–575px`, `chartBottom: 731–860px`, `legendBottom: 767–896px` across `mortgage`, `401k`, `sip`, `emi`, `income-tax-us`, `ppf`, and `debt-payoff`).
  - Switched `.calculator-detail .calculator-result-metrics` to a 6-column smart grid (`span 3` for 2/4 supporting metrics, `span 2` for 3/5/6 supporting metrics) so zero orphan slots appear on any metric count, collapsing cleanly to 2 columns on `<= 720px` and 1 column on `<= 380px`.
  - Defined `.sr-only` alongside `.visually-hidden` in `src/styles.css` so screen-reader-only series prefixes (`Remaining balance:`, `Cumulative interest:`) and chart table captions stay visually hidden (`srOnlyVisible: 0`) while remaining screen-reader accessible, cutting studio chart row height by ~60% and eliminating repetitive inline legend text.
- **Responsive tabular data tables (`R3`, `src/CalculatorLibrary.tsx`, `src/studios.css`):**
  - Added `.calculator-note-column` to `Note` cells in `CalculatorStudioVisual`'s chart data table, right-aligned numeric columns (`:nth-child(2)`, `:nth-child(3)`) with `tabular-nums` while keeping `.calculator-note-column` left-aligned, and replaced the legacy `1040px` `min-width` on `.calculator-breakdown-table-wrap table` with `min-width: 0; width: 100%;`.
  - Verified `0px` horizontal overflow across 9 dynamic resize widths (`1440 → 1200 → 1041 → 900 → 768 → 560 → 390 → 320 → 1440`).
