  - Overrode `.fire-workbench-inputs .advanced-shell .planner-grid` to `grid-template-columns: minmax(0, 1fr)` at all viewport widths so every refinement section (`Market periods`, `Retirement model options`, `One-off events`, `Recurring income streams`, `Recurring spending phases`) receives 100% of the input-workbench width inside compact `12px` inset ledger panels (`border-radius: 8px`, `background: var(--color-surface-inset)`).

  - Reset `.fire-workbench-inputs { order: 0; }` so mobile (`<= 720px`) preserves natural DOM reading order (inputs before outputs) instead of inheriting legacy `.quick-calculator { order: 2; }`.
- **Right-aligned tabular cash-flow ledger table (`R2`, `src/workspace.css`):**
