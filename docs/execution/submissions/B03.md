## Problem and change

Task B03 eliminates cross-currency contamination in financial accounts and plan seeding. Previously, account balances in disparate currencies (e.g. USD and INR) were naively summed into a single integer, causing USD 100 + INR 100 to incorrectly display as USD 200. Furthermore, plan import lacked typed validation against importing mismatched currency accounts into a plan with a different default currency.

Implemented changes:
1. **Isolated Per-Currency Summary Calculation (`summarizeAccounts` & `summarizeAccountList`)**:
   - In `functions/_lib/accounts.ts` and `src/App.tsx`, computes `accountCount`, `assetsCents`, `liabilityAccountCount`, `liabilitiesCents`, and `netWorthCents` per currency inside `byCurrency`.
   - When accounts have mixed currencies (`currencies.length > 1`), sets `hasMixedCurrencies: true`, `primaryCurrency: null`, and combined totals `assetsCents`, `liabilitiesCents`, `netWorthCents` to `null` (`Unavailable`).
   - When accounts share a single currency, sets `hasMixedCurrencies: false`, `primaryCurrency: currency`, and preserves exact integer totals with 100% backward compatibility.
   - For 0 active accounts, returns zero totals and `hasMixedCurrencies: false`.
   - Excludes inactive accounts (`isActive: false`) and archived accounts (`archivedAt`).
   - Accurately aggregates negative balances per currency without clamping or dropping.
2. **Plan Seeding Currency Matching (`src/lib/planWorkspace.ts`)**:
   - Exports `PLAN_SEED_ERROR_REASONS` enum including `CURRENCY_MISMATCH`.
   - `previewPlanSeed` checks selected account currencies against the target profile currency. If any mismatch occurs, import is blocked with typed `errorDetails` containing `reason: PLAN_SEED_ERROR_REASONS.CURRENCY_MISMATCH`, `accountName`, `currency`, and `expectedCurrency`.
3. **UI Rendering in Dashboard and Accounts Strip (`src/App.tsx`)**:
   - Added `formatAccountMetric` which displays `Unavailable` if `hasMixedCurrencies` is true or amount is null.
   - Added `formatCurrencyBreakdown` which renders an inline per-currency breakdown string (e.g. `INR: ₹100.00 · USD: $100.00`).
   - Updated `DashboardPanel` (net worth, assets, liabilities) and `AccountsPanel` overview strip to render `formatAccountMetric` with `formatCurrencyBreakdown`.
4. **API Integration & Validation**:
   - Handlers `/api/accounts` and `/api/dashboard` return the updated `AccountSummary` with `byCurrency` and currency isolation fields.
   - Added comprehensive tests in `src/accounts.test.ts` and `src/lib/planWorkspace.test.ts`.
