## Changed behavior

- **Design tokens & anti-slop surface simplification (`R1`, `src/vivid-theme.css`, `src/shell.css`, `src/styles.css`):** Set `--app-atmosphere: none`, `--action-gradient: none`, and `--text-gradient: none` across light and dark tokens, replaced gradient text on `.app .eyebrow` with solid `--color-eyebrow` at `font-weight: 600` (`letter-spacing: 0`) in both `src/vivid-theme.css` and `src/shell.css`, moved panels/buttons to opaque surfaces with 1px hairlines and `8px`/`6px` button/badge radii, and removed `!important` / `font-weight: 850` overrides on `th` and `td` in `@layer legacy` (`src/styles.css`) so `@layer studios` owns studio typography cleanly.
- **Shared studio & library CSS consolidation (`R2`, `src/studios.css`):** Added `@layer studios` rules on a strict 4px spacing grid (`0`, `4`, `8`, `12`, `16`, `20`, `24`, `28`, `32`, `48px` with zero non-grid `2/6/10/14/18/22px` values), capped `.calculator-library` heading/bold/`th`/summary/eyebrow weights at `600` (with `500` on buttons), enforced `stroke-width: 1.5` and `18px` bare muted icon boxes, migrated legacy studio selectors (`.calculator-toolkit-more a`, `.calculator-empty-state`, `.calculator-explanation-panel`, `.calculator-example-panel`, `.calculator-decision-panel`, `.calculator-related-panel`, `.estimate-customization`, `.calculator-options-shell`, `.calculator-chart-table-details`, `.calculator-chart-table`, `.calculator-history-compare`, `.calculator-faq-grid`), added `flex-wrap: wrap` on `.panel-heading`, aligned nested radii (`12px -> 8px -> 6px -> 4px`), enforced `min-width/height: 24px` interactive link/chip targets, and kept `160ms cubic-bezier(0.22, 1, 0.36, 1)` transitions.
- **Library & studio TSX copy/icon cleanup (`R3`, `src/CalculatorLibrary.tsx`):** Updated studio and help icons (`CircleHelp` and `<Icon>`) to bare muted `size={18} strokeWidth={1.5}` glyphs, removed decorative gradient/tinted icon boxes, and stripped trailing periods on single-line headlines/captions (`<h1>Start with the question, not the formula</h1>`, empty search state heading, and engagement drawer subheads).
- **Regression tests & hosted smoke coverage (`R4`–`R6`, `src/CalculatorStudioUnslop.test.tsx`, `scripts/smoke/c36-unslop-studios.mjs`):** Added 8 unit/CSS/render assertions in `src/CalculatorStudioUnslop.test.tsx` (checking absence of `!important` `850` table weights, `.app .eyebrow` weight `600`, strict 4px spacing grid compliance, and clean single-line copy), plus the `c36-unslop-studios` Playwright smoke module verifying `/calculators`, `/calculators/ppf`, `/calculators?q=FIRE`, `/calculators?q=zzzznotfound`, expanded `<details>` schedules, zero `layout.small` / overflow issues, `fontWeight <= 600` across visible `.calculator-library *`, stripped studio icons, and `.primary-button` styling.
