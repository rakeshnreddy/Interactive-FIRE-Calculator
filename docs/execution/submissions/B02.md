## Problem and change

Task B02 eliminates the vulnerability where non-USD currencies (such as `EUR`, `INR`, `GBP`) could be dropped into the currency-less `goals` table amounts (`goalPayloadFromCalculator`), corrupting financial values because `goals` schema lacks a currency column and assumes USD.

Implemented changes:
1. **Typed Rejection at Parse Boundary (`parseCalculatorSavePayload`)**:
   - In `functions/_lib/calculatorResults.ts`, when `conversionRoute === '/goals'` and `currency !== 'USD'`, returns typed error `{ code: 'INCOMPATIBLE_GOAL_CURRENCY', error: 'Goals currently support USD only. Currency conversion into goals is not supported.', ok: false }`.
2. **Defensive Guard in Payload Converter (`goalPayloadFromCalculator`)**:
   - In `functions/_lib/calculatorResults.ts`, if `payload.currency !== 'USD'`, returns `null` rather than generating an amount-corrupting goal payload.
3. **Pre-Persistence Guard with Zero Database Calls (`createSavedCalculatorResult`)**:
   - In `functions/_lib/calculatorResults.ts`, throws `IncompatibleGoalCurrencyError` (`code: 'INCOMPATIBLE_GOAL_CURRENCY'`) immediately if `destinationType === 'goal' && payload.currency !== 'USD'`, *before* `ensureUserProfile` or any statement execution.
4. **API Endpoint Error Handling (`onRequestPost`)**:
   - In `functions/api/calculator-results/index.ts`, returns HTTP status 400 with `{ code: 'INCOMPATIBLE_GOAL_CURRENCY', error: ... }` on validation or when `IncompatibleGoalCurrencyError` is thrown.
5. **Direct Goal Creation Guard (`parseGoalCreatePayload` & `parseGoalUpdatePayload`)**:
   - In `functions/_lib/goals.ts`, if an explicit `currency` other than `'USD'` is provided, rejects with `{ code: 'INCOMPATIBLE_GOAL_CURRENCY', error: ... }`. Handlers `functions/api/goals/index.ts` and `functions/api/goals/[id].ts` propagate this code with HTTP 400.
6. **Preservation of Supported Non-USD Destinations and Public Workflows**:
   - Supported routes (e.g. `/accounts` with currency column) retain arbitrary currencies (`EUR`, `INR`). Public calculation engines, share URLs, and CSV exports continue in original currency without switching.
