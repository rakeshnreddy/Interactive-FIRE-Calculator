## Changed behavior

- **2-Column Split Financial Workbench (`R1`, `src/App.tsx`, `src/workspace.css`, `DESIGN.md`):**
  - Replaced the single-column `1,561px` vertical form stack on `/calculators/fire` with `<div className="fire-workbench-grid">` inside `.workspace:has(.fire-workbench-grid)` (`width: min(1320px, calc(100% - clamp(1.25rem, 3.2vw, 2.75rem)))`, `grid-template-columns: minmax(450px, 500px) minmax(0, 1fr)` on `>= 1041px`, graceful single-column stack on `<= 1040px`).
  - Left column (`section.quick-calculator.focused-calculator.fire-workbench-inputs`) houses the core inputs, `Optional refinements` disclosure, and `Calculate` / `Recalculate` button (`bottom: 876px` at `1440×900`, fitting 100% above the fold).
  - Right column (`div.fire-workbench-outputs`) displays the `.fire-workbench-preview` overview card prior to calculation and immediately renders the full output stack above the fold upon calculation.
- **6-Column Input Subgrid, 3-Across Age Triad & Single-Border Input Controls (`R2`, `src/App.tsx`, `src/components/Field.tsx`, `src/vivid-theme.css`, `src/workspace.css`):**
  - Added optional `className?: string` prop to `Field` (`src/components/Field.tsx`) and tagged `#fire-current-age`, `#fire-retirement-age`, and `#fire-plan-end-age` with `className="fire-age-field"`.
  - Paired `Planning question` and `Currency` side-by-side (`span 3` each) at the top of `.core-fire-form`, grouped the 3 Age Triad inputs (`span 2` each, staying 3-across down to `381px` and stacking `1 / -1` on `<= 380px`), and paired money and rate fields 2-across (`span 3` each on `>= 601px`, stacking `1 / -1` on `<= 600px`).
  - Refined `.app.app .info-dot, .app.app .calculator-help-btn` in `src/vivid-theme.css` (`24×24px` WCAG 2.2 AA minimum target size) so `.app.app button` (`44px`) no longer inflates `.field-label` rows, and unified `.fire-workbench-inputs .calculator-input-control` into a clean single-border inline-unit box (`34px` high, `border: 0 !important` on inner `input`).
- **Default-Visible Interactive Projection Chart Above the Fold (`R3`, `src/App.tsx`, `src/ProjectionChart.tsx`, `src/workspace.css`):**
  - Changed initial `calculatorPanel` state from `'planner'` to `'results'` and updated `calculateNow()` and `applyLoadedSnapshot()` to set `setCalculatorPanel('results')`.
  - Added optional `height?: number` prop (`default 360`, `205` on `/calculators/fire`) and `isAnimationActive={false}` on `<Line>` elements in `src/ProjectionChart.tsx` so the year-by-year trajectory renders immediately on `Calculate` and resizes cleanly without Recharts clip-rect artifacts.
  - Placed `.hero-result` (`bottom: 419px`), `.result-tabs-panel` (`bottom: 465px`), and `#results.chart-panel` (`bottom: 836px`, rendered whenever `hasCalculated && calculatorPanel !== 'compare'`) above `.health-panel` so the primary FIRE answer and the interactive Recharts cash-flow trajectory are both 100% visible above `900px` at `1440×900` without scrolling.
- **Responsive Resize & Hosted Smoke Coverage (`R4`–`R5`, `src/FireWorkbenchUsability.test.tsx`, `scripts/smoke/c41-unslop-final-polish.mjs`):**
  - Added `src/FireWorkbenchUsability.test.tsx` (`3` suites) locking in the `.fire-workbench-grid` structure, 3-across `.fire-age-field` triad, default-mounted `.hero-result` + `#results.chart-panel` above `.health-panel`, and `24×24px` `.app.app .info-dot` target rules.
  - Extended `scripts/smoke/c41-unslop-final-polish.mjs` to trigger `Use example values` + `Calculate` on `/calculators/fire` across `1440`/`320` in `light`/`dark`, asserting `sideBySide === true` and `inputsBottom <= 900 && heroBottom <= 900 && chartBottom <= 900` at `1440×900` plus full WCAG 2.2 AA contrast and `/unslop` compliance on the calculated workbench.
