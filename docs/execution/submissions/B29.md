## Changes
- **PA-9:** the reports panel moved from `App.tsx` to `src/reports/ReportsPanel.tsx` with its insight cards unchanged. `App` re-exports it as `InsightsPanel` so the fixtures still work.
- **Scope header** (`src/reports/reportScope.ts`, shown before any guidance):
  - as-of date
  - which plan is used (saved name and version, or "unsaved calculator draft")
  - account count, and how many balances are stale (older than 45 days or undated)
  - currencies present
  - active goals
  - transaction count and date range
- **Data gaps in plain words:**
  - Missing accounts or transactions are described as "unavailable, not zero".
  - Mixed currencies are "never added across currencies".
  - A transaction window under a month is flagged as possibly unrepresentative.
- **Loading state:** while saved data loads, the scope is `aria-busy` with a loading note instead of false empty-data gaps. The C10 hosted run found this.
- **CSV export** (`buildReportCsv`): the scope and gaps, then one row per evidence item, using exactly the strings shown on screen.
- **Print:** hides navigation and buttons, forces a light background, expands the assumption sections and avoids splitting cards. No new dependency.
- **Colour:** priority is always written as text ("Accounts / High"), not colour alone.
