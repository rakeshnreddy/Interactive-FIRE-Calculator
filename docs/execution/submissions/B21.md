## Problem and change

User problem:
In generic calculators across `CalculatorLibrary`:
1. Zero values (e.g. Month 0 interest, Month 360 principal balance, zero tax or zero extra payment) rendered with an artificial minimum 8% bar fill width (`Math.max(8, ...)`), falsely displaying zero quantities as positive values.
2. Negative values (e.g. negative returns or net cashflow deficit) were passed through `Math.abs()`, inverting negative quantities into positive bars and concealing signs.
3. The `.calculator-visual-bars` block rendered the first 4 output metrics on a single comparison bar chart, absurdly normalizing completely unrelated units (e.g. $1,896 monthly payment, $382,633 interest, and 360 months tenure) onto one scale.
4. Secondary series (e.g. comparison values or base references) lacked formatted text values and swatch associations in the legend.
5. Screen reader users and keyboard users had no accessible semantic tabular alternative to the visual bar representations.

Implementation:
1. True Zero Geometry:
   - Eliminated artificial minimum bar fill widths. When value is zero, bar fill width is strictly `0%`.
   - Added subtle `.calculator-zero-marker` pin at the zero line to indicate presence of a measured zero value without conveying positive magnitude.
2. Signed Geometry & Baseline:
   - Removed `Math.abs()` sanitization in `src/lib/calculatorStudios.ts` (`waterfallChart` and `comparisonChart`).
   - Implemented signed bar positioning relative to a dynamic zero baseline (`.calculator-chart-baseline`). Negative values extend to the left of the baseline and carry `.is-negative` styling with danger/warning tones.
3. Removed Heterogeneous Multi-Unit Comparison:
   - Completely eliminated `.calculator-visual-bars` multi-metric bar chart that normalized unrelated units.
4. Dual Series Text & Swatch Legend:
   - Rendered explicit text values for both primary and secondary series (`.primary-val` and `.secondary-val`).
   - Added `.calculator-legend-swatch` elements (`.swatch-primary` and `.swatch-secondary`) pairing visual bars with the chart legend.
5. Semantic Tabular Alternative:
   - Added an accessible semantic table (`<table className="calculator-chart-table">`) inside a collapsible `<details className="calculator-chart-table-details">` section, with proper `th[scope="col"]` and `th[scope="row"]` headers.
6. Responsive Styling & Pure Calculation:
   - Updated `src/styles.css` with responsive layout for tracks, swatches, zero markers, baselines, and data tables.
   - Preserved all underlying financial calculation formulas with zero changes to `src/lib/fire.ts`.
