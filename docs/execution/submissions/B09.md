## Problem and change

User problem:
Internal backlog phrasing, roadmap milestones, and developer directives were leaking into the user-facing experience (audit V14). Specifically:
1. The amortization chart summary on `/calculators/amortization` and loan tools displayed: `"This preview uses the same payment math as the calculator and gives Phase 22 a schedule-ready primitive to expand."`
2. Calculator "Decision checks" for loan, retirement, and return studios displayed developer implementation tasks such as `"Connect loan results to a liability account or payoff plan."`, `"Connect the result to a saved retirement plan or retirement account."`, and `"Route users toward a saved investment goal or performance note."`
3. The unconfigured authentication gate (`AuthGate`) exposed developer setup instructions and leaked private environment variable names (`VITE_CLERK_PUBLISHABLE_KEY`, `CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY`, `CLERK_AUTHORIZED_PARTIES`), and the session checking state leaked vendor-specific plumbing ("Clerk session").

Implementation:
1. In `src/lib/calculatorStudios.ts`:
   - Replaced Phase 22 chart summary with clean user-facing copy: `"This preview uses the same payment math as the calculator to show how your balance declines and interest accumulates over time."`
   - Refined APR breakdown, cash-to-close, and tax breakdown summaries to use direct, active voice instead of third-person developer phrasing.
2. In `src/lib/calculatorQuality.ts`:
   - Replaced internal directives in `interpretationChecks` with actionable, user-centric financial decision guidance across all studios (Loan and Home, Retirement Income, Return Analysis, Cashflow and Balance Sheet, Growth and Goal).
   - Removed "Phase 25" export reference and "comprehensive tax phases" from formula quality overrides (`amortization` and `tax-rate`).
   - Replaced internal account connection directives with user-centric planning context descriptions.
3. In `src/App.tsx`:
   - Updated `AuthGate` when unconfigured to display honest, user-facing copy:
     - Heading: `"Account features are currently unavailable."`
     - Description: `"Saved plans, accounts, and cross-device sync require account services that are not active in this preview. You can use all interactive financial calculators without an account."`
     - Removed the entire `auth-env-list` DOM element (zero environment variables or setup commands leaked to users).
     - Added an honest disabled action for unavailable account access (`"Account features unavailable"` with `disabled` / `aria-disabled="true"`).
     - Added a primary working action navigating directly to the public tools (`"Explore public calculators"`).
   - Neutralized loading state copy to `"FinPath is confirming whether there is an active session for this browser."` (removed vendor leak) and added working navigation to `/calculators`.
   - Updated legacy `CalculatorsPage` heading and description to clean user-facing copy.
   - Preserved strict fail-closed auth preflights on all platform routes.
4. Added comprehensive regression tests:
   - `src/lib/calculatorQualityCopy.test.ts`: Guards all 82 calculators and studios against phase numbers, SEO terminology, and developer implementation directives.
   - `src/authGateCopy.test.tsx`: Tests unconfigured, loading, and signed-out AuthGate copy, privacy, and public navigation.
