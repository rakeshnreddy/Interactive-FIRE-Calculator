## Problem and change

User problem: The landing page previously featured a generic full-bleed stock photograph of a mobile device and payment card (`/assets/finpath-product-hero.jpg`), accompanied by aspirational, metaphorical copy ("Make the number mean something") that obscured the actual product capability. In C03 initial submission, the hero SVG plotted `portfolioMode` ($500k start) while labeling assumptions as $60,000/yr, and the chart ancestor had `aria-hidden="true"`, hiding the meaningful outcome from assistive tech (Review findings R1 & R2).

Implementation & Rework Fixes:
1. Exact copy contract implemented in `src/App.tsx`: Eyebrow "Plan your financial future", Headline "See when you could retire.", supporting text "See how saving more or spending less could change your retirement timeline. Try it free, without an account.", and clean single-sentence privacy copy "Use the public calculators before deciding whether to create an account."
2. Primary public CTA links directly to `/calculators/fire` ("Explore my retirement timeline") and secondary link to `/calculators` ("Explore all calculators"). Retained popular start links (`/calculators/mortgage`, `/calculators/debt-payoff`, `/calculators/compound-interest`, `/calculators/fire`).
3. R1 Financial Model Fix:
   - `<HeroFireExample />` plots `result.expenseMode`, aligning the trajectory with the modeled target ($965,931) and the displayed $60,000/yr initial annual spending.
   - Starting balance is explicitly identified as the modeled target ($965,931), with a clear explanation that the separate gap of $465,931 is between current savings ($500,000) and this target.
   - Assumption label explicitly states "Initial annual spending: $60,000/yr" and "30-year horizon".
   - Completely deleted string-based `formatted.initialPortfolio > '$0' ? 'Sustained' : 'Depleted'` branch. Rendered numeric "Modeled end balance: $0" (`result.expenseMode.finalBalance` rounds to $0).
   - Dynamically derived X-axis years (`Year 0`, `Year 15`, `Year 30`) and rendered zero baseline line and USD curve amount labels ($965,931 and $0).
4. R2 Accessible Chart Semantics:
   - Removed `aria-hidden="true"` from chart container.
   - Implemented an exposed `<figure className="hero-example-chart">` with `<figcaption className="hero-example-chart-header">`.
   - Used stable React `useId()` IDs for `aria-labelledby` and `aria-describedby`.
   - Provided concise text alternative (`.visually-hidden`) naming scenario, 30-year horizon, start/end years, USD start/end balance, initial annual spending, inflation, and nominal return.
   - SVG given `role="img"`, `<title>`, and `<desc>`, while decorative icons remain `aria-hidden="true"`.
   - Programmatic AX tree dump verified via Chrome CDP (`docs/execution/evidence/B18/native-home-ax.txt`).
5. Replaced vague capability bands with one concrete three-step sequence ("Add your numbers", "Try different assumptions", "Review the results") and three useful planning paths ("Buying a home?", "Growing your savings?", "Long-term independence?").
6. Removed `public/assets/finpath-product-hero.jpg` (219 KB saved) and cleaned all CSS background references.
7. Styled 2-column desktop (1440px) and stacked mobile (390px) responsive layout in `src/vivid-theme.css` using canonical light/dark tokens and opaque surfaces for financial values. Reset `<figure>` margin to 0.
