## Product defects found by the hosted run and fixed (with regression tests)
1. **Spurious "Unsaved changes" dialog** (`d4bc06e`):
   - **Cause:** loading a snapshot fills newer fields (for example `recurringCashFlows`), but the workspace compared against the raw snapshot with order-sensitive JSON. Any older saved plan looked dirty, and the revise prompt's "Open calculator" asked to discard changes the user never made.
   - **Fix:** `hasUnsavedAssumptions` in `src/lib/planWorkspace.ts` compares the same normalization the app applies, with a stable key order. 3 tests.
2. **Revise journey could not save Version 3** (`a09ff46`):
   - **Cause:** "Back to Planning Workspace" navigates to a bare `/plans`. In-app navigation treated the missing `planId` as an unknown deep link, showed "Saved decision unavailable" and cleared the active plan, which disabled "Save new version". Back/forward already handled this correctly.
   - **Fix:** both paths now share `resolvePlansRouteAction` (`src/lib/navigation.ts`). 2 tests.
