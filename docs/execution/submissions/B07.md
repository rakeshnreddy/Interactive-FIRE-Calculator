Task B07 establishes the honest deletion, export, and disaster recovery contract for FinPath95. In response to C06 review findings R2 and R4:

1. **Atomic Deletion Triggers & Boundary Enforcement (`migrations/0006_user_tombstone_triggers.sql`, `functions/_lib/persistence.ts`, `functions/_lib/accounts.ts`)**:
   - Implemented `BEFORE INSERT` and `BEFORE UPDATE` SQLite triggers across all 14 child tables (`user_profiles`, `financial_accounts`, `account_balances`, `transactions`, `goals`, `plans`, `plan_versions`, `fire_plan_inputs`, `fire_plan_results`, `assumptions`, `audit_log`, `balance_imports`, `transaction_imports`, `saved_calculator_results`) aborting writes on tombstoned users:
     ```sql
     SELECT RAISE(ABORT, 'USER_DELETED: user has been tombstoned');
     ```
   - Added resurrection guard trigger on `users`:
     ```sql
     CREATE TRIGGER IF NOT EXISTS trg_prevent_resurrection_users
     BEFORE UPDATE OF deleted_at ON users
     FOR EACH ROW
     WHEN OLD.deleted_at IS NOT NULL AND NEW.deleted_at IS NULL
     BEGIN
       SELECT RAISE(ABORT, 'USER_DELETED: cannot un-tombstone a deleted user');
     END;
     ```
   - Hardened `handleApiError`, `ensureUserProfile`, `createAccount`, and `recordBalance` to catch `USER_DELETED` SQLite aborts and return HTTP 410 `UserDeletedError`.
