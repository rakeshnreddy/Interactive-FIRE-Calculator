## Problem and change

1. **Atomic Deletion Before First Initialization & Tombstone Preservation (`functions/_lib/accountData.ts`)**:
   - Replaced update-only `userTombstone` with atomic `INSERT INTO users (...) VALUES (?, 'clerk', ?, ?, ?, ?) ON CONFLICT(id) DO UPDATE SET deleted_at = COALESCE(users.deleted_at, excluded.deleted_at), updated_at = excluded.updated_at` bound to `(userId, userId, now, now, now)` in the exact same purge batch.
