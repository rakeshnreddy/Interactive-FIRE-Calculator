## Problem and change

User problem: The calculator library previously suffered from visual monotony (audit V13): eight large repeated panels with prominent, competing count badges, repeated "Also useful" label pills across every secondary link, and absence of the interactive FIRE calculator from both the main starting discovery grid and the search filter results.

Implementation:
1. Four question-led starting decision paths rendered prominently above the toolkit grid:
   - "Planning for retirement?" → **Interactive FIRE Calculator** (`/calculators/fire`)
   - "Buying a home?" → **Mortgage Payment Calculator** (`/calculators/mortgage`)
   - "Growing your savings?" → **Compound Interest Calculator** (`/calculators/compound-interest`)
   - "Paying off debt?" → **Debt Payoff Calculator** (`/calculators/debt-payoff`)
2. Surfaced FIRE explicitly in discovery and search without duplicating `seoCalculators` registry math. Searching for "FIRE", "fire", "retirement timeline", "financial independence", etc., returns a dedicated `FireSearchCard` pointing to `/calculators/fire`.
3. Removed repetitive "Also useful" badge decoration across all toolkit panels. The primary link receives an understated `Start here` tag, and secondary links render as clean, readable rows with title and arrow.
4. Styled toolkit counts as secondary/subtle metadata (`.calculator-toolkit-count`).
5. Preserved search input robustness: case-insensitive, whitespace-trimmed, query clearing, deep-link URL parameter `?q=` support, and empty-state guidance for queries yielding 0 matches.
6. All 82 registry SEO calculators plus FIRE remain fully discoverable and reachable via native `<a href="...">` links.
