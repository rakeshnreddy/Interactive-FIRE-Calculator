## Problem and change

The primary reviewer's C01T review identified that while B32 delivered the luminous mineral palette, atmosphere gradients, and visibly distinct hero treatments, several defects and verification gaps required rework:
1. **R1 (Print Legibility)**: In dark mode, `.landing-hero-media` and `.landing-hero-scrim` remained visible over black text; header elements lacked solid print pairings; non-essential navigation remained in print; print contrast had not been verified with background graphics both enabled and disabled.
2. **R2 (Composited Contrast & Fallbacks)**: Prior verification assumed nominal endpoints rather than measuring actual pixel luminance of the composed background beneath text; fallbacks for `prefers-reduced-transparency`, `forced-colors`, `print`, and unsupported `backdrop-filter` lacked comprehensive sampling and dual-engine documentation.
3. **R3 (Real Accessibility)**: Real browser 200% zoom reflow needed verification across 6 distinct routes in both light and dark themes; screen reader testing needed an honest accounting without claiming an unsupported pass; programmatic accessibility tree needed capture.
4. **R4 (Comparative Performance Benchmark)**: Benchmark needed a side-by-side comparison between candidate and baseline `1c870e2` under identical setup, including scrolling framerate and duration deltas.
5. **R5 (Verification Reliability & CI Attribution)**: The verification harness required strict nonzero exit status on any failure, console error trapping, durable log output, and accurate CI attribution showing product-tree equivalence.

### Solution implemented:
1. **R1 Print Legibility Overhaul in `src/vivid-theme.css`**:
   - Re-bound all variables in `@media print` on `.app` and `.app[data-mode="dark"]` to pure `#ffffff` canvas, `#000000` text, and `#d0d7de` borders.
   - Explicitly hid `.landing-hero-media` and `.landing-hero-scrim` (`display: none !important`) so dark photo and scrim never print behind text.
   - Hid non-essential navigation overlays (`.mobile-nav`, `.desktop-nav-dropdown`) (`display: none !important`).
   - Paired all `.topbar` elements with `#000000` foreground and `#ffffff` / transparent surfaces.
   - Styled all planning path strip cards with `#ffffff` backgrounds, `#000000` text, and `#d0d7de` borders.
   - Added `overflow-x: clip` to `body, .app` ensuring sticky topbar behaves properly on scroll.
2. **R2 Composed Pixel Sampling & Fallback Verification**:
   - Upgraded `docs/execution/evidence/B32/verify_b32.cjs` to sample raw pixel luminance under text via `sharp` pixel extraction.
   - Sampled worst-case and intermediate stops (0%, 25%, 50%, 75%, 100%) for all hero elements, buttons, and scrolled topbar glass over 500px content.
   - Tested all 4 fallbacks (`prefers-reduced-transparency`, `forced-colors`, `print` with bg graphics on/off, and unsupported `backdrop-filter`).
   - Primary engine (Chromium) verified; secondary engines (WebKit, Firefox) truthfully recorded as `blocked` due to missing local binaries, with reviewer manual verification requested.
3. **R3 Real 200% Zoom & Accessibility Verification**:
   - Verified real 200% browser zoom across 6 routes (`/`, `/calculators`, `/calculators/fire`, `/calculators/mortgage`, `/calculators/savings-goal`, `/dashboard`) in both light and dark modes (12 configurations). 0 horizontal overflow.
   - Captured programmatic accessibility tree via CDP `Accessibility.getFullAXTree` for Home, Library, FIRE, and Auth Gate.
   - VoiceOver screen reader truthfully recorded as `blocked` due to headless CI agent lacking macOS TCC accessibility permissions, with reviewer assistance requested.
4. **R4 Comparative Performance Benchmark**:
   - Built baseline `1c870e2` at `/tmp/finpath-baseline-dist` and candidate `dist/`.
   - Ran 3-run side-by-side benchmark measuring FCP, DCL, load, bundle size, and scrolling framerate/duration/dropped frames.
   - Saved results to `docs/execution/evidence/B32/performance-comparison.json`. Zero regressions detected.
5. **R5 Verification Gate & Durable Logging**:

   - Enforced strict nonzero exit status on any failure.
