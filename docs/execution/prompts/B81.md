## Outcome and acceptance (Option A — Split Financial Workbench)

- **R1 (2-Column Split Financial Workbench Above the Fold):** Wrap `/calculators/fire` in `.fire-workbench-grid` (`src/App.tsx`, `src/workspace.css`): on desktop (`min-width: 1041px`), place `.quick-calculator.focused-calculator.fire-workbench-inputs` (`440px`–`480px` left column) beside `.fire-workbench-outputs` (`minmax(0, 1fr)` right column) starting at the top of the workbench (`y < 260px` at `1440×900`). On `<= 1040px`, stack cleanly in a single column with zero horizontal overflow at `320px`.
- **R2 (Compact Input Craft & 3-Across Age Triad):** Fix `.app.app .info-dot` and `.app.app .calculator-help-btn` in `src/vivid-theme.css` (`min-width: 24px; min-height: 24px; min-block-size: 24px; width: 24px; height: 24px`, WCAG 2.5.8 AA compliant) so field labels are compact. Lay out `.core-fire-form` inside `.fire-workbench-inputs` on a 6-column grid where the 3 age fields (`Current age`, `Retirement age`, `Plan end age`, `.fire-age-field`) form a 3-across Age Triad (`span 2` each) and money/rate pairs form a 2×2 grid (`span 3` each), keeping the primary `Calculate` / `Recalculate` button visible above the `900px` desktop fold (`bottom <= 880px`).
- **R3 (Default-Visible Interactive Projection Graph & Above-the-Fold Answer Ledger):**
  - Before calculation (`!hasCalculated`), render `.fire-workbench-preview` in `.fire-workbench-outputs` (while keeping `.hero-result` `null` per `OD-1` / `resultReveal`), offering a one-click `Use example values` shortcut and explaining what appears once calculated.
  - When `calculateNow()` or `applyLoadedSnapshot()` runs, set `calculatorPanel` to `'results'` (and render `#results.chart-panel` whenever `hasCalculated && calculatorPanel !== 'compare'`) so **both** `.hero-result` AND `#results.chart-panel` (the interactive `<ProjectionChart />` / `<YearByYearTable />`) are mounted and visible by default immediately below `.hero-result` in `.fire-workbench-outputs`, with `.health-panel` positioned below `#results`/`#compare`. At `1440×900`, `.hero-result` (`top < 300px`) and the interactive chart canvas (`.chart-panel`, `top < 650px`) must both be visible above the `900px` fold immediately after clicking **Calculate** without scrolling.
- **R4 (Preservation & Verification):** Preserve all existing FIRE math (`src/lib/fire.ts`), `OD-1` empty required initial rates, `B24` stale/recalculate lifecycle, `R1`–`R3` regressions in `src/FireCalculator.test.tsx`, `src/fireAssumptions.test.tsx`, `src/fireRetirement.test.tsx`, and `src/lib/resultReveal.test.tsx`, sitewide `/unslop` CSS invariants (`border-radius <= 12px`, `font-weight` in `400`/`500`/`600`, WCAG 2.2 AA contrast), full `./scripts/test_all.sh`, exact-head CI, candidate & shared-beta verification, production root (`https://interactive-fire-calculator.pages.dev/`) deployment, and `main` merge.
