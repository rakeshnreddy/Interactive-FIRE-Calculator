# B65 — Gratuity table ends at the entered service

C27, with B64. Baseline main `6413640`.

**Source convention (inspected):** `gratuity` returns `min(salary × 15/26 × years, ₹20,00,000)` using service years exactly as entered. The existing scope (B49) deliberately states "Service years are used exactly as entered" and excludes "service rounding" and entitlement; this contract keeps that model. No statutory part-year rule is applied or claimed: the Labour Codes FAQ already cited by the scope returned HTTP 403 on 2026-10-04 and was not re-read, so no new legal statement is made.

**Reproduced evidence (`evidence/C27/raw/baseline.json`):** 8.5 entered years → headline ₹5,88,461.54, but the "Completed service" table ends at year 9 at ₹6,23,076.92; 2.5 years → ₹1,73,076.92 versus a year-3 row ₹2,07,692.31.

## Outcome and scope

| ID | Requirement |
|---|---|
| R1 | Table rows at whole years, then the exact entered service (e.g. 8.5) whose benefit equals the headline (Decimal 588461.5384615385). |
| R2 | The part-year row notes that service is used exactly as entered and statutory counting of a part year is not applied, consistent with the scope. Existing vesting/ceiling notes kept. |
| R3 | Whole-year rows and every result unchanged; zero service gives no table. |

**Non-goals:** statutory rounding, eligibility, wage definition, Labour Code changes, model version, production.

**Tests:** failing first with the oracle; whole-year rows equal baseline; CSV last row equals headline. **Migration:** presentation only. Human 0.5h; agent 0.5h.
