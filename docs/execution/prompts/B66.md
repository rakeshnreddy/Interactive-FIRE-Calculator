# B66 — Truthful generated input helpers

C28. Owner said "continue"; follows the C27 handoff item on generic helper copy. Baseline: main after C27 (PR #150).

**Source convention (inspected):** `defaultInputHelper` in `seoCalculators.ts` writes the helper for every input without an explicit one, from the label and type alone. Helpers are copy only — no calculation, validation or saved data reads them (they appear in the field description and the quality spec's input requirements).

**Reproduced evidence (2026-10-04 survey of all 359 inputs on 82 routes, `evidence/C28/raw/helpers-baseline.json`):**

| Generated text | Inputs / routes | Defects |
|---|---|---|
| "Enter the X as an annual percentage unless the label says otherwise." | 86 / 66 | Wrong for shares that are not yearly rates: down payment percent, GST, TDS, stamp duty, registration, closing cost, transfer/funding fees, salary exemption cap, EMI-to-income, PF/payroll deduction; "unless the label says otherwise" hedges instead of informing. |
| "Enter the X as a recurring amount in the calculator currency." | 48 / 35 | Wrong for one-time amounts (Foreclosure payment, Recast principal payment) and balances (Current 401(k)); never says how often. |
| "Enter the X in years." | 52 / 49 | Tautology "Enter the years in years." on 15 inputs; "Pay periods per year" is told to be entered in years. |

## Outcome and scope (generator only; explicit helpers untouched)

| ID | Requirement |
|---|---|
| R1 | Percent: labels for taxes, duties, fees, closing costs, down payment, caps, income ratios and payroll/PF deductions read "Enter as a percentage, for example 18 for 18%." (no "annual"); other rates read "Yearly rate as a percentage, for example 7.5 for 7.5% a year." No "unless the label says otherwise". |
| R2 | Currency: a label with "monthly" reads "Amount each month in the calculator currency."; with "annual", "yearly" or "CTC" reads "Amount each year in the calculator currency."; anything else keeps the neutral "Enter the X in the calculator currency." No "recurring amount". |
| R3 | Counts and years: "period"/"per year" labels are checked before years ("Number of pay periods in a year; for example, 26 for biweekly pay."); a years label reads "Number of years; 1.5 means 18 months." or "X in years; 1.5 means 18 months." — no tautology. |
| R4 | Explicit helpers, keys, defaults, limits, validation and results unchanged. |

**Non-goals:** hand-written helpers per route, any route's explicit copy, labels, results, schema, production.

**Tests:** failing first — none of the three defective phrasings on any route; the named one-time/share/period cases get correct text; every input still has a non-empty helper; explicit helpers unchanged (FD/CD/RD/PPF samples); results/defaults unchanged. Full suite, CI, hosted spot check on three routes.

**Analytics/privacy/migration:** none; copy only; rollback reverts one function. **Dependencies:** B60–B65 (explicit helpers). Human 1h; agent 0.5h.
