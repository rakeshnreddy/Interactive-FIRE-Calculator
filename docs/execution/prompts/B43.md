## Implement exactly this bounded scope

Required FIRE return/inflation already appear in the main form: retain their placement and OD-1 empty/required/example-action behavior. Add a prominent Customize this estimate affordance directly after the input heading and before lengthy helper copy, connected to real controls with keyboard focus. Rename FIRE advanced grouping around optional market periods, retirement model and future cash flows; summary must describe optional settings rather than repeating base-rate errors. When base rates are unset, first-period display must not misleadingly look like an entered 0%; show an unset state without changing serialized math. Separate generic Pay extra from Include housing costs. Show active option count and meaningful entered summaries; mortgage initial P&I explicitly says costs are omitted until supplied. On extra-mortgage-payment and mortgage-payoff, extra monthly payment belongs in the main visible entry area because it is the primary job. Move distracting other-preset chips below the primary answer. Keep additive defaults neutral zero and disclose omissions; never zero required rates or rewrite contractual timing.
