# B72 — Cross-field and boundary validation across Loan, Return, Tax, and Retirement studios

C34. Registered 2026-11-14 from `main` `0f5492d6e67594a95afd84146e848128fb0bca55`, after accepted `B76` / `C39` ([PR #161](https://github.com/rakeshnreddy/Interactive-FIRE-Calculator/pull/161)). This checkpoint executes the 7 surviving input-boundary and cross-field validation findings from [the October 18 multi-agent analysis](../../calculator-excellence/ANALYSIS_2026-10-18.md) (`LH-02`, `LH-07`, `RET-02`, `RINC-04`, `RINC-05`, `TAX-03`, `RINC-15`) across Loan & Home, Return Analysis, Income & Tax, and Retirement Income studios.

## Outcome and acceptance (`B72 / C34` contract)

1. **`LH-02` — Sub-1-year loan terms (`0 < years < 1`) and `years <= 0` rejection:**
   - Remove hidden `Math.max(1, years)` clamps on `loan-comparison` and `rent-buy` in `src/lib/seoCalculators.ts`, and replace `Math.max(1, values.years ?? 1)` across loan schedule builders in `src/lib/calculatorStudios.ts` (`loanAmortizationSchedule`, `aprBreakdownSchedule`, `balloonLoanSchedule`, `biweeklyLoanSchedule`, `fhaConventionalComparisonSchedule`, `loanComparisonSchedule`, `loanPrepaymentSchedule`, `mortgageRecastSchedule`, `armPaymentSchedule`, `pointsBreakEvenSchedule`, `refinanceComparisonSchedule`, `rentBuySchedule`) with `termMonths(...) / 12` so `0 < years < 1` (e.g. `0.5` = 6 months) reconciles between headline metrics and schedule tables.
   - Reject `years <= 0`, `compareYears <= 0`, `loanYears <= 0` across borrowing/loan formulas (`loan`, `amortization`, `apr`, `balloon-loan`, `biweekly-loan`, `arm`, `points`, `fha-loan`, `va-loan`, `fha-conventional`, `flat-rate-loan`, `interest-only-loan`, `loan-comparison`, `loan-eligibility`, `loan-prepayment`, `mortgage-recast`, `refinance`, `rent-buy`) in `src/lib/calculatorInputState.ts`.
2. **`LH-07` — Cross-field loan & home validation:**
   - Reject `downPayment >= homePrice` on financed-only loan routes (`fha-loan`, `va-loan`, `fha-vs-conventional`) and reject `downPayment > homePrice` on general purchase routes (`closing-costs`, `rent-vs-buy`, `pmi`, `lease-vs-buy`).
   - Reject `closingCosts >= principal` (and `principal <= 0`) on `apr`.
   - Reject `fixedYears <= 0` and `fixedYears >= years` on `arm-mortgage`.
   - Reject `balloonYears > years` on `balloon-loan`, while preserving `balloonYears = 0` (`B71` month-0 immediate balloon).
3. **`RET-02` — Return Analysis zero-denominator boundaries:**
   - Require `initial > 0` and `years > 0` on `investment-return` and `cagr`; return `null` from `investmentReturnSchedule` when `initial <= 0` or `term <= 0`.
   - Require `years > 0` and `(initial > 0 || monthly > 0)` on `xirr`; return `null` from `xirrApproximationSchedule` when `years <= 0` or `(initial <= 0 && monthly <= 0)`.
   - Require `rate > 0` on `rule-of-72`; return `null` from `doublingSchedule` when `rate <= 0`.
4. **`RINC-04` — PPF minimum deposit & whole-year >= 1 bounds:**
   - Set `ppf` `annual.min = 500` (matching PPF Scheme 2019 minimum ₹500/year) and `years.min = 1, years.step = 1`, while keeping `'PPF runs in whole financial years. Enter a whole number, such as 15 or 20.'` for fractional positive years (`15.5`).
5. **`RINC-05` — RMD life expectancy divisor >= 1:**
   - Set `rmd` `divisor` input metadata to `min: 1, max: 100, step: 0.1`, reject `< 1` in `validateCalculatorInputs`, and align `calculateSeoCalculator` `case 'rmd'` (`Math.max(1, get('divisor'))`) with `rmdSchedule`.
6. **`TAX-03` — Paycheck integer pay periods `1..365` & schedule reconciliation:**
   - Set `paycheck` `periods` metadata to `min: 1, max: 365, step: 1`, reject `< 1`, `> 365`, and non-integer `periods` in `validateCalculatorInputs`, and align `calculateSeoCalculator` `case 'paycheck'` with `paycheckSchedule` using `Math.max(1, Math.round(get('periods')))`.
7. **`RINC-15` — Retirement age bounds and ordering:**
   - Set `currentAge` and `retirementAge` metadata to `min: 0, max: 120, step: 1` on `retirement` (`401k` uses investment `years` rather than age inputs).
   - Reject `retirementAge < currentAge` in `validateCalculatorInputs`, while preserving `retirementAge === currentAge` (`B68` immediate-retirement test) and `60.125` compatibility for saved-history restoration tests.
8. **Verification & Release:**
   - Write failing regression tests first in `src/CalculatorBoundaryValidation.test.tsx`, pass `./scripts/test_all.sh`, pass independent adversarial review, add `scripts/smoke/c34-boundary-validation.mjs` for `scripts/hosted_smoke.mjs`, verify exact-head CI, deploy and smoke-test candidate + shared beta (`codex/finpath-quality-execution`), record closure artifacts in `docs/execution/evidence/C34/`, update trackers (`RESUME.md`, `START_NEXT_TASK_PROMPT.md`), and merge PR to `main`.
