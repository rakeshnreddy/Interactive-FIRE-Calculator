## Outcome and acceptance (`B73 / C35` contract)

1. **`CBS-01` — Net Worth `toNetWorthResult` headline & saved account metric order (`src/CashflowPlanningCalculator.tsx`):**
   - Put `{ description: 'Total assets minus total liabilities.', label: 'Estimated net worth', tone: projection.netWorth < 0 ? 'warning' : 'positive', value: projection.netWorth, valueType: 'currency' }` at `metrics[0]` in `toNetWorthResult`, followed by `Total assets` (`metrics[1]`), `Total liabilities` (`metrics[2]`), `Liquid assets` (`metrics[3]`), and `Liquid position` (`metrics[4]`).
   - Saving `/calculators/net-worth` to `/accounts` then records `Estimated net worth` (`17500000` cents / `$175,000` on default inputs instead of gross `$250,000`) via `functions/_lib/calculatorResults.ts`, and `HistoryPanel` displays `Estimated net worth`.
2. **`CBS-02` — Emergency Fund `incomeStability` saved snapshot persistence (`src/CashflowPlanningCalculator.tsx`):**
   - Persist `incomeStability` via numeric code `incomeStabilityCode` (`0` = `'stable'`, `1` = `'variable'`, `2` = `'uncertain'`) in `numericEmergencyInputs` when saving `/calculators/emergency-fund`, and decode `incomeStabilityCode` in `loadSaved` (defaulting legacy snapshots without `incomeStabilityCode` cleanly to `'stable'`), restoring `riskReferenceMonths` and `riskReferenceTarget`.
3. **`CBS-04` & `CBS-05` — Life Insurance Needs supporting metrics, chart breakdown, category, assumptions, and overfunded narrative (`src/lib/seoCalculators.ts`, `src/lib/calculatorStudios.ts`):**
   - Map `formula === 'insurance'` to `category: 'Planning'` instead of `'Investing'`.
   - In `calculateSeoCalculator` (`case 'insurance'`), add explicit assumptions disclosing that `income * years` is an undiscounted nominal multiple (excluding investment returns, inflation, taxes, survivor benefits, and underwriting), add an overfunded narrative branch when `need === 0 && grossNeed > 0`, and return supporting metrics (`Income replacement need`, `Debts and final expenses`, `Existing savings / coverage`).
   - Add `insurance: ['income-replacement', 'debts', 'existing-coverage', 'coverage-gap']` to `costIds` in `selectedModelChart` so the Protection gap waterfall chart reconciles with `insuranceNeedsSchedule` and the `$1,050,000` headline.
4. **`CBS-07` — `CashflowPlanningCalculator` saved-history formatting, select error accessibility, and locale forwarding (`src/CashflowPlanningCalculator.tsx`):**
   - Format `HistoryPanel` metric values (`moneyFormatter`, `percent`, `number`) and dates using `resolvedLocale` (eliminating unformatted float strings).
   - Add optional `error` rendering (`aria-invalid="true"`, `aria-describedby` including error id, `.field-error` alert) to `PlanningSelectField` and pass `projection.validation.errors.incomeStability` / `householdEarners`.
   - Forward `resolvedLocale` into `EmergencyRunway` and `BreakdownTable` percent formatters.
5. **`RINC-07` — FIRE Withdrawal mode blank optional `Need benchmark` and solved withdrawal projection (`src/App.tsx`):**
   - When `calculatorMode === 'withdrawal-income'` and `annualExpense` is blank (`NaN`), sanitize `annualExpense` to `0` at engine evaluation boundaries (without modifying `src/lib/fire.ts`) so no false `CRITICAL` error warning is emitted for `annualExpense`, show `'No benchmark set'` on `Need coverage` (instead of `'Not feasible'`), and display `portfolioMode.rows` (`'Annual withdrawal projection'`) for the solved withdrawal path in `Results`.
6. **`RINC-12` — FIRE `planWarnings` currency formatting (`src/lib/warnings.ts`, `src/App.tsx`):**
