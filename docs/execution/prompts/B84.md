# B84 / C45 — Stage 2: Option A Split Financial Workbench & above-the-fold charts for the 7 dedicated calculators

## Context & Problem Statement

Following Stage 1 (`B83 / C44`), which brought the calm Option A Split Financial Workbench and above-the-fold charts to all 75 shared studio calculators, seven dedicated calculators still exhibit vertical bloat, orphaned metric slots, misaligned input/select heights, notched `<fieldset><legend>` borders, legacy 3px colored top panel stripes, or charts pushed below the `900px` desktop fold:

- `/calculators/compound-interest` (`src/CompoundInterestCalculator.tsx`): `Where the balance comes from` stacked bar chart is cut in half below `900px`; `select` controls are `44px` tall next to `36px` `.calculator-input-control` fields; `.estimate-customization` wraps a lone `Display only` chip; panels carry legacy `3px` colored top borders.
- `/calculators/savings-goal` (`src/SavingsGoalCalculator.tsx`): `Funding runway` chart sits completely below `900px` (`top: 796px`, `bottom: 1158px`) because the 8 metric cards render in a 3-column grid with an orphan 3rd-row blank slot (`3 + 3 + 2`).
- `/calculators/budget`, `/calculators/net-worth`, `/calculators/emergency-fund` (`src/CashflowPlanningCalculator.tsx`): 5 metric cards in a 2-column grid leave an empty right-half orphan slot on row 3 (`2 + 2 + 1`), `<fieldset><legend>` cuts through card borders, and `Reset` wraps onto a second line on Emergency Fund.
- `/calculators/xirr?returnMode=dated` (`src/XirrCalculator.tsx`): `.calculator-mode-choice` consumes `138px` at the top with stacked buttons, the single supporting metric leaves an orphan right half, and `CashFlowTimeline` SVG is clipped below `900px`.
- `/calculators/lease-vs-buy` (`src/VehicleCalculator.tsx`): the single supporting metric leaves an orphan right half, `44px` inputs stretch the form to `1,425px`, and the second resale-equity visual is pushed below `900px`.
