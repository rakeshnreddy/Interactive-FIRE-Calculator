## Outcome and acceptance

- **R1 (WCAG 2.2 AA Contrast Repair):** Switch `.info-dot` and `.compound-base-label` text color to `var(--color-primary-ink)` (bumping `.compound-base-label` to `0.75rem` / `12px`), and style `.compound-chart-legend` and `.savings-runway-chart .compound-chart-legend` text in `var(--color-body)` while moving series colors strictly onto `::before` swatches (preserving all `repeating-linear-gradient` and hollow-border pattern redundancies). Zero visible text contrast failures (`< 4.5:1` normal / `< 3.0:1` large) across all 20 audited routes × `1440`/`320` × `light`/`dark`.
- **R2 (Semantic Link Styling & Dark Overscroll Hygiene):** Set `color: var(--color-body)` on `.starting-path-card` (`src/studios.css`) and semantic `color: var(--color-primary-ink)` with clean underline offset on bare inline `.route-shell a:not([class])` and `.calculator-methodology-panel a` links (`src/workspace.css`). Sync `html:has(.app[data-mode="dark"]), body:has(.app[data-mode="dark"])` background to dark canvas (`#090f19`) so overscroll in dark mode never flashes `#f4f7f7`.
- **R3 (AuthGate H1 Copy Cleanup):** Remove trailing periods from all 3 `AuthGate` H1 titles in `src/App.tsx` (`Account features are currently unavailable`, `Checking your session`, `Sign in to open ${page.eyebrow}`) and update assertions strictly pinned to those trailing periods (`src/authGateCopy.test.tsx`, `src/appParity.test.tsx`, `src/shellNavigation.test.tsx`, `scripts/run_local_browser_checks.mjs`).
- **R4 (Complete Legacy CSS Radius & Weight Alignment):** Normalize the final 13 `border-radius: 14px`/`16px`/`18px` declarations (to `12px` / `8px`) and 2 `font-weight: 560` declarations (to `500`) in `src/styles.css`, ensuring **zero** CSS files across `src/*.css` contain `border-radius > 12px` or off-scale weights outside `400`/`500`/`600`.
- **R5 (Verification, Hosted Release & Gemini Argon Review Handoff):** Add red-phase regression suite `src/UnslopFinalPolish.test.tsx` and shared hosted smoke scenario `scripts/smoke/c41-unslop-final-polish.mjs` verifying real OKLCH-resolved WCAG AA contrast, zero unstyled UA links, zero off-scale weights/radii/gradients/blur/trailing-period H1s, and live performance metrics (LCP, CLS, transfer sizes) across representative routes in light & dark themes. Pass `./scripts/test_all.sh`, independent adversarial review, exact-head CI, candidate and shared-beta deploys, 84 public routes, and write comprehensive review handoff notes for Gemini Argon in `docs/execution/GEMINI_ARGON_REVIEW_NOTES.md`, then merge to `main`.
