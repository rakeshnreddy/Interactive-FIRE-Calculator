# C19 model migration decision — 2026-09-30

Preserve loan payments and positive-denominator payback arithmetic. Remove the artificial numeric zero for absent payback/catch-up; retain a numeric zero only for a genuine zero cost/forgone amount with positive saving/increase. Add explicit model-version metadata to result JSON; no new database column or backfill. Version field must survive client/server parsing, CSV and canonical idempotency hashing; unversioned hashes remain byte-identical. Legacy records keep their numeric snapshots; explicit restore recalculates with a visible interpretation notice, explicit save creates a new record. Current result and schedule summaries state the interpretation; charts plot actual currency flows, never undefined payback as zero. CFPB refinancing and SSA references are context, not mathematical oracles. Formula fixtures are independently derived in the feature contract. FIRE arithmetic is unchanged. Rollback preserves version read support even if current UI behavior is reverted.
