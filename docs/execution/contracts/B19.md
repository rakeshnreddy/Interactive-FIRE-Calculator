Non-goals / preserved files and successful behavior: No new calculator engines, no ranking copy, no new external search libraries, no modified calculator formulas or math. Preserved exact routes (`/calculators/fire`, `/calculators/mortgage`, etc.) and canonical theme tokens.
Applicable authorization and free-tier limits: Free services only; local Vitest/Playwright tests; Cloudflare Pages preview; zero production writes or main merge.
