# C21 vehicle-cost migration decision — 2026-09-30

Give /calculators/lease-vs-buy its own vehicle-cost formula and direct editor. Housing rent-vs-buy stays unchanged. Source: FTC financing/leasing guidance https://consumer.ftc.gov/articles/financing-or-leasing-car (checked 2026-09-30): compare total cost, not monthly payment alone. Resale is a user estimate, never an automatic valuation.

At the same horizon, buy net cost = down payment + actual loan payments paid + remaining loan − resale; equity = resale − remaining loan. Lease cost = upfront amount excluding regular payments + quoted monthly payment × months within quote + entered continuation payment × extra months. Beyond the offered period requires an explicit checkbox and continuation amount; this extends F-03's constant-payment example without inventing a renewal quote. Loan payments stop at payoff. Fixed monthly interest uses APR/12; each payment reduces accrued interest then principal. A final payment clears the actual remainder. Positive/zero APR fixtures and an independent nonzero balance formula verify it. Amounts bounded to 1e12, rates 0–100%, positive whole-month durations at most 100 years; at most 1,200 payment steps. Negative equity and net cost remain signed.

Required terms/resale start empty; optional upfront is visibly 0, continuation is off and empty. Explicit example fills a complete independently derived case. No implicit tax/mileage/maintenance/insurance/termination/opportunity-cost estimates. Display net-cost bars on one currency scale and a separate signed ownership-value/equity breakdown with exact table; monthly payment is a separate metric, never the chart's competing total.

Version vehicle-cost-v1 uses existing numeric maps and result JSON. New saves route to a plan comparison. Validate all model inputs/version/slug/destination server-side; no schema, data backfill or remote writes. Read original historical alias snapshots without changes; explicit restore leaves missing resale/lease period empty and requires review. No inferred resale. CSV exports terms and reconciled outputs on explicit action. No financial values in analytics or URLs. Rollback may disable the editor but keeps version read/export support. FIRE and housing math remain unchanged.
